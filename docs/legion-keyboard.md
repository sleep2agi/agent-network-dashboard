# 军团的键盘与读屏操作（2026-10-27）

给 QA / 后续维护者：这张表两个页面（`/legion`、`/legion/3d`）都在用，改交互时
请一起更新。

## 通用

| 操作 | 行为 |
| --- | --- |
| `/` | 聚焦本页搜索框（全站 Quick search 用 `⌘K/ Ctrl+K`，军团页里 `/` 归本页） |
| `?` | 打开/关闭键盘速查表（**在军团页里优先于全站 HelpOverlay**，见下） |
| `Esc` | 一次只退一样：先关速查表 → 再清搜索词 → 再取消选中 |
| `Tab` | 逐项浏览（节点列表、详情卡按钮、图例） |

## 3D（`/legion/3d`）

| 操作 | 行为 |
| --- | --- |
| 拖动 / 方向键 | 旋转视角（水平是 yaw，垂直是 pitch） |
| 滚轮 / 双指 / `+` `-` | 缩放（滚轮以指针为锚点；底部显示当前倍率） |
| 点节点 | 选中并显示详情卡 |
| 双击节点 / `Enter` | 打开详情（Agent → `/nodes/<alias>`；成员/部门 → `/org`） |
| 双击空白 | 复位视角（含缩放锚点） |
| `R` | 复位视角 |
| 节点列表按钮 | 打开后焦点自动进第一项；↑/↓ 移动、回车选中；成员 >60 时只列部门与核心 |
| 详情卡「聚焦所在部门」 | 选中 Agent/成员时可用；未分组/无主 Agent 不显示（合成节点不是部门） |
| 详情卡「复制」 | 复制节点名到剪贴板，1.2s「已复制」反馈 |

## 2D（`/legion`）

| 操作 | 行为 |
| --- | --- |
| 拖动 | 平移视图 |
| 滚轮 | 缩放（以指针为锚点）；右下有倍率与 ± 按钮 |
| 点节点 | 选中并显示右侧详情 |
| `Enter` | 打开选中节点（Agent → 节点页；成员/部门 → `/org`） |
| 空格 | 折叠/展开选中的部门（焦点在节点上时由节点自己处理，避免双触发） |
| 节点列表按钮 | 同 3D（打开即聚焦第一项、↑/↓ 移动、回车选中） |
| 双击图 | 复位视图 |

## 约定（改代码时注意）

1. **输入框里的按键一律放行**：`INPUT/TEXTAREA/SELECT` 内的方向键、空格、加减号
   都归输入框，只有 `Esc` 例外（清词、保持焦点）。两页都有 `inField` 守卫。
2. **`/` 与 `?` 会与全站组件抢**：CommandPalette 绑 `/`、HelpOverlay 绑 `?`。
   军团页用「捕获阶段 + stopImmediatePropagation」（2D）或 React `stopPropagation`
   （3D）让本页优先；全局面板仍可从命令面板进入。新增快捷键前先 grep 全站有没有冲突。
3. **节点列表的 Tab 数量**：成员 ≤60 才列 Agent，否则只列部门与核心 —— 否则
   400 节点会出现几百个 Tab 停点。
4. **Canvas 没有 DOM**：3D 的读屏靠 `aria-describedby` 指向的 sr-only 说明 +
   详情卡 `aria-live="polite"`；改画布交互时别把这两处删了。

5. **列表里的回车只负责选中**：焦点还在 `[role=listbox]` 内时，全局「回车打开」
   会让位（否则按一下就跳页）。要打开详情，先把焦点移出列表（Tab 到舞台）再回车。
