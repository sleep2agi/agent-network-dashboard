## 4. 怎么复验

**一条命令跑完（推荐）**

```bash
./deploy/legion-verify-all.sh                    # 默认打线上
./deploy/legion-verify-all.sh http://localhost:3106
```

覆盖 6 支探针并输出一行结论：`LEGION-VERIFY: PASS (6/6)`
（drift-clip · label-drop · pitch-param · visual-spotcheck · projector · site-scroll；退出码可直接进 CI）

**逐支跑（工作区 `evidence/probes/`）**

```
legion-label-drop.mjs            标签留存（320/390/1440 × 四变体）
legion-visual-spotcheck.mjs        三页 × 两视口截图 + 结构量（画布/zoom/溢出/正文长度/pageerror）
legion-canvas-text-contrast.mjs  画布文字对比度（深色 + 浅色，16 组，判据 ≥4.0）
legion-cold-start.mjs            冷启动（每视口 3 次取中位数）
site-scroll-audit.mjs            全站整页滚动条普查（路由从 app/**/page.tsx 生成）
legion-export-check.mjs          导出产物（2.5s 条件必须含真实头像）
legion-plaza-smoke.mjs           平台视角冒烟（标题+计数可读 / 卡片>1 / 无 pageerror）
legion-drift-clip.mjs            取景越界/裁切（实体 vs 页面安全区；VP_ONLY=1440 可单档重复）
legion-projector.mjs             投屏/显示器 5 档（1024×768 · 1280×720 · 1280×1024 · 1366×768 · 1920×1080）
                                 **3D 与 2D 都覆盖**（3D：画布/zoom/越界；2D：SVG/节点数/溢出），判据 45 条
legion-fit-timeline.mjs          取景时间线（每 500ms 采 safeBounds/zoom/writer，覆盖率 <60% 判不可用）

量法纪律（踩坑换来的，务必遵守）：
  1) 整页高度类指标至少两档视口（1000 与 2400）
  2) 采样前先断言健康横幅已就位（--health-banner-h 非空）
  3) 移动端还要扣外壳的底部让位（--shell-bottom-pad）
  4) 越界类指标的分母用页面自己的安全区 [data-safe-bounds]，不要用画布
     （画布含页头/工具栏：320 按画布算 28%，按安全区算 94%）
  5) 越界判据是"越出 ≤ 16px"（= 页头前的最小间隙），不是"必须为 0"
  6) 取景/动画类指标必须等**收束**（连续 2s 不变 + 知道 writer），固定 sleep 会读到过渡值
```
