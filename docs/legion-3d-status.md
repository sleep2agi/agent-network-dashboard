## 跨引擎验证：现状与成本（2026-11-14 实测）

Chromium 已覆盖（12 门与验收套全部跑在 Chromium）。WebKit / Firefox 的浏览器二进制已下载，
但系统缺运行时库，启动即失败。实测缺失清单：

| 引擎 | 缺失 | 最小安装命令 | 规模 |
|---|---|---|---|
| Firefox | `libgtk-3-0t64` `libpangocairo-1.0-0` `libcairo-gobject2` `libgdk-pixbuf-2.0-0` | `sudo apt-get install libgtk-3-0t64 libpangocairo-1.0-0 libcairo-gobject2 libgdk-pixbuf-2.0-0` | **4 个包** |
| WebKit | GTK4 + GStreamer + flite 共 20+ 个（`libgtk-4.so.1`、`libgst*.so.0`、`libflite*.so.1` …） | `sudo npx playwright install-deps webkit` | **几十个包** |

```
⇒ 想覆盖 Safari 内核：一次 sudo + 几十个包
⇒ 想只覆盖 Firefox：一次 sudo + 4 个包（成本低得多，建议先做这个）
⇒ 装完能验证：军团两页的取景/文字对比度/滚动条/拖动缩放重置，各跑一遍三档视口
```

## `/legion/plaza`（平台视角）：现状与观测缺口（2026-11-14 实拍）

军团有三页：`/legion`（2D）、`/legion/3d`、`/legion/plaza`（平台视角）。前两页有 272 项验收与 6 个探针，
plaza **没有任何自动化断言** —— 本轮用实拍 + 三时刻采样补上第一次观测。

| 观测 | 结果 |
|---|---|
| 页面结构 | 标题 + 计数（13 个展台 · 9 名成员 · 347 个 Agent）+ 5 个视图按钮 + 画布上浮动的展台卡片 + 底部操作说明 |
| 数据到达 | 3s 时 8 个卡片元素、docScroll 1031；15s 时 92 个、docScroll 1542 ⇒ **渐进加载，不是卡死** |
| 「正在读取节点状态与属性…」 | 3s/8s 采样时已消失（首帧截图曾出现，属加载期文案，会自行结束） |
| 「模型未上报」 | 15s 时 3 处 —— 是真实数据状态（该 Agent 的会话未上报模型），不是取数失败 |
| 整页溢出 | 1440：598px、390：886px —— 内容本来长（卡片 + 说明），属正常滚动 |
| 窄屏 | 无横向溢出 |

```
结论：plaza 没有发现功能缺陷。
缺口：它没有验收套覆盖。若后续要改这一页，建议先补一条最小断言
     （标题与计数存在、卡片数 > 0、无 pageerror），否则改了也没人能证明没退化。
```
