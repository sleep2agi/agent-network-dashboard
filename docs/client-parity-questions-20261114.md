# 客户端对齐：给客户端节点的问题清单（2026-11-14）

目的：把「客户端有没有 / 表现是否一致」从模糊状态变成可勾选的三态答案。
每条只需要回答 **有 / 没有 / 表现不同（并一句话说明不同在哪）**。

## A. 军团（组织架构图）

1. 客户端是否有「组织架构图」视图？（不是列表，是图形化）
2. 若有：是否区分 2D / 3D 两种呈现？
3. 客户端是否显示「部门 → 成员 → 名下 Agent」三环结构？
4. 客户端是否有状态图例（运行中 / 空闲 / 阻塞 / 错误 / 未上报）并带数字？
5. 客户端图例在**数据未到时**显示的是 0 还是占位符（—）？—— 我们刚改成「—」，需要对齐
6. 客户端是否支持点部门聚焦、折叠展开下级？
7. 客户端是否有「净屏 / 演示模式」（隐藏界面只看图）？

## B. 节点与任务

8. 客户端节点卡片显示哪些字段？（在线、daemon 托管、MCP、模型、工作目录、会话…）
9. 客户端能否启动/重启/接管节点？权限判断在客户端还是 Hub？
10. 客户端任务列表是否显示「失败近 24h」这类健康横幅？

## C. 消息

11. 客户端长消息是否折叠？折叠高度与我们一致吗（420px / 视口一半取小）？
12. 客户端消息时间显示是本地时区还是 UTC？

## D. 主题与可读性

13. 客户端是否有浅色主题？若有，3D/2D 军团图在浅色下是否也换配色？
14. 客户端空态（无成员/无数据）是怎么表达的：降透明度、还是虚线/文本？

## 回答方式

```
每条一行：编号 + 有/没有/不同 + 一句说明（不同时附截图或描述）
我们这边对应的实现与判据都在 docs/legion-3d-status.md 与 docs/legion-3d-variants.md
```
