## 方法论沉淀（这五个版本反复验证）

1. **把 opacity 折算进有效色**：不计祖先链 opacity 的对比度检查会高估比值（`.`526` 之前 25 处漏检）。
2. **空态用形状表达，不用降低文字不透明度**：实线 + 填充 = 有内容；虚线 + 无填充 = 空。
3. **同一家族会随数据状态逐个暴露**：`flowLinks=0` 时暴露 active-links，`workingCount=0` 时暴露 working —— 修一个要顺手对齐整族。
4. **验收工具自己也会错**：探针两次误报（量错消息 / locator 因属性变化换对象），判据不变，改取样方式。
5. **发布链一次只跑一条**：`.git/release-in-progress` 会拦住误启动；读输出太早会误判"生成已结束"，以 `deploy/` 里脚本文件和进程 pid 为准。
