# 军团图使用说明（给演示 / PPT / 日常排查用）

两个页面，同一份通讯录投影：

| 页面 | 地址 | 适合 |
| --- | --- | --- |
| 3D 拓扑 | `/legion/3d` | 投屏、PPT 首图、汇报「体量感」 |
| 2D 同心环 | `/legion` | 需要读清每个部门/成员位置、截图归档 |
| 列表视图 | `/org` | 当通讯录用：部门树、成员、负责人 |

三层结构：**圆心 = 网络** → **第二圈 = 部门** → **第三圈 = 成员** → **外圈 = 成员名下的 Agent**。
颜色只表达状态：运行中（绿）/ 空闲（蓝灰）/ 阻塞（黄）/ 错误（红）/ 未上报（灰）。

---

## 一、做一张 PPT 首图（30 秒）

1. 打开 `/legion/3d`
2. 点右上 **全屏**（或按 `F`）
3. 点 **净屏**：标题、按钮、图例全部隐藏，只剩拓扑
4. 想强调"现在谁在跑"：点底部图例的 **运行中**（再点取消）
5. 点 **导出 PNG**（导出图自带标题、部门/成员/Agent 数量、图例、时间；
   带筛选时会写"仅显示 运行中"）
6. `Esc` 退出净屏 → `Esc` 退出全屏

> 第一次打开会有一个 0.9 秒的镜头推近（62% → 取景比例）；系统开了"减少动态效果"
> 的用户会直接落位。同一会话只播一次。

---

## 二、图例就是筛选器

底部图例每一档都能点：**只看该状态的 Agent**，其余压暗、不画标签；部门与成员环保留作背景。
再点一次取消，`Esc` 也能清。图例上的数字是该状态 Agent 的数量，五档合计 = Agent 总数。

排查用法：
- "谁在跑" → 点 **运行中**
- "有没有卡住的" → 点 **阻塞** / **错误**
- "哪些 Agent 没上报状态" → 点 **未上报**（通常是节点离线或版本太旧没上报）

---

## 三、分享"某个部门/某个节点"的视角

- 选中部门 → 详情卡「聚焦此部门」→ 地址栏变成 `?focus=<部门名>`（复制整个地址发给别人）
- 任意节点：详情卡右上 **复制链接** → 得到 `?node=<名字>`（Agent 用 alias、成员用显示名）
- 两个参数可叠加；对方打开就落在同一个视角、同一个选中节点

---

## 四、键鼠

| 操作 | 效果 |
| --- | --- |
| 拖动 | 环绕旋转 |
| 滚轮 / 双指 | 缩放（以指针为锚点） |
| `F` | 全屏 / 退出全屏 |
| `R` | 重置视角（重新按内容取景） |
| `/` | 聚焦本页搜索（不弹全站命令面板） |
| `?` | 打开本页速查表 |
| 点节点 / 双击 | 看详情 / 直接打开对应页面（Agent → 节点页，部门/成员 → `/org`） |
| 列表内 `↑` `↓` + 回车 | 移动选中；回车两次打开 |
| `Esc` | 依次清：净屏 → 状态筛选 → 搜索 → 取消选中 |

## 五、口径与边界（别把图读错）

- **未上报** = 该 Agent 没有 session 状态（节点离线/旧版本没上报），不是"空闲"。
- 成员环亮、Agent 环淡是刻意的明度分层；成员亮不代表有 Agent 在跑，看 Agent 环的颜色。
- 部门/成员来自 `/api/hub/people` + `/api/hub/departments`；Hub 没有部门树接口时
  按部门名扁平分组（页面有提示，不是降级错误）。
- 没有任何成员时显示空态；读取失败显示"读取军团编制失败 + 重试"，**不会伪装成空**。
- 手机端底部导航没有 Legion 入口，从左上角侧栏进入；375 宽下列表与详情互斥，不会互相压。
